# Практическое задание к Лекции 05. Этапы разработки программного продукта

## Задача (пункт 5 лекции)

Разработать **модуль учёта времени** для системы управления задачами:

1. Старт/остановка таймера для задачи
2. Учёт общего затраченного времени
3. Генерация отчётов по времени
4. Интеграция с существующей системой задач

# Что было сделано

# 1. Новый модуль — `time_tracker.py`

Новый файл проекта. Содержит:

- **`TimeEntry`** — запись об одном сеансе работы над задачей (время начала и окончания);
- **`TimeTracker`** — модуль учёта времени, интегрируется с готовым `TaskManager`:
  - `start_timer(task_id)` / `stop_timer(task_id)` — запуск и остановка таймера (с защитой от повторного запуска и несуществующих задач);
  - `get_task_time(task_id)` / `get_total_time()` — суммарное время по задаче и по всем задачам (идущий таймер тоже учитывается);
  - `generate_report()` / `print_report()` — отчёт по времени в виде словаря/JSON и в читаемом виде.

# 2. Главный файл запуска

**`time_tracker.py`** теперь объединяет весь проект: при запуске он последовательно вызывает демонстрации всех этапов разработки из всех файлов (требования → проектирование → реализация → учёт времени → канбан → сопровождение → развёртывание).

## Как запустить

```bash
# Весь проект целиком (все этапы подряд):
python3 time_tracker.py

# Только тесты (13 тестов: 5 исходных + 8 новых):
python3 test_task_system.py

# Любой этап отдельно:
python3 requirements_analysis.py   # сбор требований
python3 system_design.py           # проектирование
python3 task_manager.py            # реализация
python3 agile_kanban.py            # Agile / канбан
python3 maintenance_monitoring.py  # сопровождение
python3 deployment_script.py       # развёртывание
```

# Результаты проверки

- Все демонстрации запускаются без ошибок;
- Тесты: **13 пройдено, 0 провалено**;
- Скрипт развёртывания проходит все 4 этапа (проверка окружения → зависимости → копирование файлов → тесты).
